# 微信 Agent 社交链接层设计定义 — 2026-05-19

## 背景

Linka 第一版验证的是活动场景里的 Agent 人脉工具：主办方创建活动，参会者把邀请码交给自己的 AI 助手，Agent 加入活动、沉淀画像、获取参会者列表并做推荐。该能力最初通过 MCP 验证；当前 MCP 协议层已退役，活动 legacy 能力迁移为 REST API。

这个流程证明了 Agent 可以代表用户参与人脉场景，但它仍然偏“活动工具”。在国内微信生态里，真实传播路径更可能发生在私聊和群聊：用户收到一张小程序卡片，点开后完成连接，而不是复制链接给另一个外部 Agent。

下一阶段需要把 Linka 从“活动人脉工具”升级为“微信关系链上的 Agent 社交链接层”。

## 核心定义

Linka 让用户的 AI 助手接管微信里的社交链接：私聊建立一条边，群聊形成一个网。

小程序是前台，负责在微信里被分享、点开、查看、确认和触发连接。Agent 是后台，负责理解用户、维护状态、判断连接机会、生成推荐和跟进。

用户点击 Linka 小程序卡片后的核心动作不是“加入活动”，而是：

> 让我的 AI 助手接管这里的社交链接。

## 两种建联模式

### 单点建联：私聊

当 Linka 小程序卡片在私聊中发送时，它代表两个人之间的一次 Agent-to-Agent 建联。

用户点开后，双方的 AI 助手互相交换可连接状态，形成一条可长期维护的社交边。这个连接不是一次性的微信加好友动作，而是被双方 Agent 理解、记忆、跟进的关系。

可能产生的结果：
- 双方 Agent 生成互相介绍和连接理由
- 双方 Agent 记住这段关系
- 后续在合适时机提醒跟进
- 连接从“有联系方式”升级为“知道为什么值得联系”

### 网络建联：群聊

当 Linka 小程序卡片在群聊中发送时，它代表在这个群里开启一个共享社交链接网络。

点开的人都成为同一个网络里的节点，每个人的 AI 助手维护自己的节点状态。群本身不只是消息容器，而是被 Linka 覆盖上一层 Agent 维护的人脉网络。

可能产生的结果：
- 群成员成为网络节点
- 节点状态由各自 Agent 持续维护
- 网络里出现推荐、匹配、引荐、状态流
- 活动群、饭局群、项目群、创业者互助群都可以成为一个临时或持续的社交网络

## 与第一版的区别

第一版的容器是活动，核心动作是“把邀请码发给 Agent，加入一个活动”。下一阶段的容器是微信关系场景，核心动作是“点开小程序，让我的 AI 助手接管这里的社交链接”。

| 维度 | 第一版：活动人脉 MVP | 下一阶段：微信 Agent 社交链接层 |
|------|----------------------|--------------------------------|
| 入口 | MCP 客户端、邀请链接、二维码 | 微信小程序卡片 |
| 容器 | 活动 event | 私聊关系、群聊网络 |
| 核心动作 | 加入活动 | 接管这里的社交链接 |
| 用户对象 | 参会者 attendee | 节点 node、边 edge |
| 状态模型 | 加入时的静态画像 | Agent 持续维护的可连接状态 |
| 价值承诺 | Agent 帮你发现活动人脉 | Agent 替你维护微信里的社交链接 |

活动不是被否定，而是退化为群聊网络建联的一种特殊场景。

## 产品原则

- 绑定 Agent 是一次性初始化，不是每个场景都重复设置。
- 用户不需要持续维护自己的社交状态，Agent 负责代管。
- 小程序不替代 Agent，小程序负责微信内顺手进入和查看，Agent 负责后台理解和维护。
- 私聊强调建立一条关系边，群聊强调形成一个共享网络。
- 状态不是“在线/离线”，而是“我现在适合被怎样连接”。

## 绑定技术方案

mini-wx 阶段固定采用小程序绑定码 + Linka Skill REST API 认领方案。MCP 协议层不参与当前产品路径。

小程序确认微信用户身份并生成一次性绑定码。用户把绑定码交给自己的 Agent，Linka Skill 调用 Linka API 认领绑定，后端返回 `agent_token`。后续 Skill 使用 `agent_token` 更新用户状态、建立连接和维护社交链接。

详细方案见 [微信小程序绑定 Agent 技术方案](./2026-05-19-skill-api-agent-binding-design.md)。

## 后续设计入口

下一阶段产品设计应围绕三件事展开：

1. 首次初始化：用户如何连接自己的 AI 助手，并授权它维护社交链接。
2. 私聊建联：两个人如何通过小程序让各自 Agent 建立一条长期社交边。
3. 群聊建网：群成员如何通过同一张小程序卡片进入同一个 Agent 维护的社交网络。
